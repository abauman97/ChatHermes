## Remaining incremental migration

Shared workflows now cover project instructions/context, saved native Cron output, streamed thinking, approvals, generated-artifact histories and background execution. Scheduled dispatch itself, further thinking variants, notification suppression, native OS pickers and presentation edge cases still have retained coverage awaiting complete workflow replacements. Do not count the old fixture-dependent suites as passing the new harness, or remove them until corresponding real-Hermes scenarios pass.

The current phase replaces the setup and foundational user journeys. Native OS file/camera pickers, production HTTPS push delivery, physical devices, and remote-daemon live execution require their own evidence; CDP file injection and endpoint rewriting alone do not establish those contracts.
