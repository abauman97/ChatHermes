# Issue #7 verification and limitations

## Outcome

This is a guarded, browse-only compatibility preview, NOT completion of #7.
The native Project model exists, but neither installed Hermes nor pinned source
3632f9173d218fd24f3fa595d7affa159b0774cd has an explicit chat/Project relationship.
Desktop places chats using cwd/repository heuristics. Gateway session creation
ignores cwd/project_id. No native API satisfying the issue's required association
can be reused. Full creation, grouping, Project-session resume and context tests
therefore remain blocked upstream. No parallel mapping or active Project state
was introduced. See ../plans/2026-10-01-projects.md for the source audit.

## Changed files and APIs

- src/components/ProjectSidebar.vue: touch-friendly native Project list.
- src/App.vue: selection, query URL persistence, metadata, errors, navigation
  cancellation, focusable composer with Project sending gated.
- src/components/SessionSidebar.vue: Other chats label and 16px rename input.
- src/types/hermes.ts, src/lib/hermes-api.ts: metadata projection and authenticated
  same-origin plugin calls. These are plugin adapters, not invented Hermes REST.
- plugin/chathermes/dashboard/plugin_api.py: `/projects` and `/projects/{id}`
  adapters reuse `projects_db.connect_closing/list_projects/get_project` and
  `Project.to_dict`; existing dashboard auth and profile routing remain in force.
  POST `/sessions` and `/api/sessions` refuse Project/cwd fields with 501 before
  forwarding anything to the gateway, which otherwise silently ignores them.
- src/projects.test.ts, src/App.test.ts, tests/plugin_api.test.py,
  tests/visual/projects.spec.ts: automated coverage.
- README.md, source plan, this report, and rebuilt dashboard/dist assets.

No initial workspace is set by this preview: Project chat creation is blocked.
Normal Hermes context loading is unchanged; no instructions are injected.
Other chats use existing session/messages/chat/run APIs and cancellation.

Limitations: no live gateway/provider calls, progressive network SSE delivery,
attachment uploads, physical camera, iOS keyboard, or Desktop app end-to-end
resume were verified. Browser fixtures verify disclosure state transitions, not
live arriving tool data. The full pre-existing gateway visual suite could not
run without compose. Project creation, explicit grouping, workspace initialization,
Project-session URL resume, and context inheritance remain unsupported rather
than being falsely reported as passing. Source/base-image pins are unchanged.

No commit, push, PR, or deployment was performed. Existing untracked preview-root
files were untouched. Test processes and temporary native state are separate
from repository runtime state.

Preservation limitation: Playwright's default output-directory cleanup removed
the pre-existing ignored `tests/visual-output/picker-review/` screenshot artifacts.
Those prior captures were not preserved. Repository source and pre-existing
untracked preview-root.html/preview-root.ts were not changed.
