# Issue #7 implementation plan and source audit

Read `gh issue view 7 --repo abauman97/ChatHermes` verbatim before editing.
Inspected installed `/opt/hermes` and downloaded the exact compose source pin
`3632f9173d218fd24f3fa595d7affa159b0774cd` to `/tmp/chathermes-pin`.

1. Native model: `hermes_cli/projects_db.py`, `Project` and `ProjectFolder`,
   profile-local `projects.db`; `list_projects`, `get_project`, `primary_path`.
   Desktop RPC `tui_gateway/methods_projects.py`: `projects.list`, `projects.get`.
2. Sessions: `hermes_state_sessions.py` / `SessionDB`, native `state.db`;
   stores `cwd`, `git_repo_root`, `git_branch`, but NO Project foreign key.
3. Plugin currently uses authenticated gateway REST `/api/sessions`, detail,
   messages, chat/stream, and run cancellation. No gateway Projects REST exists.
4. Desktop: `apps/desktop/src/app/chat/sidebar/projects/overview-row.tsx`,
   `app/session/hooks/use-session-actions/index.ts`: passes `cwd` through
   `session.create` RPC, not a Project ID. `tui_gateway/project_tree.py` assigns
   memberships using folder/cwd and repo-root heuristics. A Project ID on the
   tree is an output grouping identifier, not a persisted session relationship.
5. Desktop `tui_gateway/methods_session.py` initializes explicit `cwd`, resumes
   stored cwd, and builds agents with `cwd_override`. REST
   `gateway/platforms/api_server.py::_handle_create_session` inserts only ID,
   source, model, model_config, system_prompt, started_at; ignores cwd/project_id.
   `agent/prompt_builder.py::build_context_files_prompt` preserves precedence:
   .hermes.md/HERMES.md, then AGENTS chain, then CLAUDE, then Cursor rules.
6. Integrate native read-only metadata through cookie-authenticated plugin routes,
   add touch-friendly Project selection and existing query-parameter navigation.
   Keep all chats accessible without falsely assigning them by path. Explicitly
   block Project creation/sending on this unsupported backend, including server
   requests that the upstream would silently treat as generic session creation.
   Test profile isolation, metadata, errors, navigation, and fail-closed creation;
   rebuild assets and inspect real dashboard screenshots at both sizes.

## Upstream blocker / scope limitation

The required explicit relationship does not exist in either inspected source.
Full issue completion requires an upstream persisted chat Project relationship,
create API accepting that relationship and cwd, a runtime honoring stored cwd,
list/detail exposure, and Desktop adoption. Adding a mobile-only mapping or using
Desktop's path heuristics would violate this issue. Do not claim this guarded
browse-only implementation completes #7. Keep compose source and image pins.
