`3632f9173d218fd24f3fa595d7affa159b0774cd` at
`/opt/data/profiles/developer/cache/scratch/hermes-pin-3632f917`.

   add touch-friendly Project selection and existing query-parameter navigation.
   Keep all chats accessible without falsely assigning them by path. Explicitly

   requests that the upstream would silently treat as generic session creation.
   Test profile isolation, metadata, errors, navigation, and fail-closed creation;

## Upstream blocker / scope limitation

The required explicit relationship does not exist in either inspected source.
Full issue completion requires an upstream persisted chat Project relationship,
create API accepting that relationship and cwd, a runtime honoring stored cwd,
list/detail exposure, and Desktop adoption. Adding a mobile-only mapping or using
Desktop's path heuristics would violate this issue. Do not claim this guarded
browse-only implementation completes #7. Keep compose source and image pins.

Re-inspected the exact local pin at
